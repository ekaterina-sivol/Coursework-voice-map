# GameVote

GameVote — веб-приложение для голосования за карту и игровой режим в сетевой игре.

Проект разработан в рамках курсовой работы по дисциплине «Проектирование и разработка серверных частей интернет-ресурсов».

## Функциональные возможности

- Регистрация и авторизация пользователей.
- Создание игровых лобби вместимостью от 2 до 10 игроков.
- Присоединение к существующим лобби.
- Голосование за карту и игровой режим.
- Изменение своего голоса до завершения голосования.
- Ограничение времени голосования до 60 секунд.
- Автоматический подсчёт голосов и определение победителей.
- Случайный выбор победителя при равенстве голосов.
- Повторные голосования и сохранение истории раундов.

## Используемые технологии

- PHP 8.3

- HTML5

- JavaScript
- Apache

Серверная часть приложения разработана с использованием архитектурного шаблона MVC.

- `app/Controllers` — контроллеры приложения.
- `app/Models` — модели и работа с базой данных.
- `app/Views` — представления страниц.
- `app/Core` — основные компоненты приложения.
- `config` — конфигурация подключения к базе данных.
- `database` — SQL-скрипты создания и заполнения базы данных.

- `docker` — конфигурация образа PHP и Apache.

## Запуск проекта

Для запуска необходимо установить Git и Docker Desktop.

### 1. Клонирование репозитория

```bash
git clone https://github.com/ekaterina-sivol/Coursework-voice-map.git GameVote
cd GameVote
```

### 2. Настройка переменных окружения

Создайте файл `.env` на основе файла `.env.example`.

Для Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Для Linux и macOS:

```bash
cp .env.example .env
```

Укажите собственные пароли в переменных `DB_PASSWORD` и `DB_ROOT_PASSWORD`.

### 3. Запуск контейнеров

```bash
docker compose up -d --build
```

При первом запуске автоматически создаются таблицы базы данных и добавляются начальные данные игровых карт и режимов.

### 4. Открытие приложения

Перейдите в браузере по адресу:

http://localhost:8080

### 5. Остановка приложения

```bash
docker compose stop
```

Для повторного запуска:

```bash
docker compose up -d
```

Данные пользователей, лобби и результаты голосований сохраняются в отдельном хранилище Docker.

## Правила голосования

Голосование запускается создателем лобби при наличии не менее двух участников.

Каждый участник может выбрать одну карту и один игровой режим. До истечения 60 секунд пользователь может изменить свой выбор.

Победителями становятся карта и режим, получившие наибольшее количество голосов. При равенстве голосов победитель выбирается случайным образом среди лидеров. При отсутствии голосов выбор осуществляется случайно среди всех доступных вариантов.

После завершения голосования результаты сохраняются в базе данных. Создатель лобби может запустить новый раунд.
